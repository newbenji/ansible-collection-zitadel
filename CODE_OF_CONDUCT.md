# Code of Conduct

This project follows the
[Ansible Community Code of Conduct](https://docs.ansible.com/ansible/latest/community/code_of_conduct.html).

In short: be respectful, assume good intent, and keep discussions on topic. Report
unacceptable behaviour to the maintainer, [@newbenji](https://github.com/newbenji),
through a private
[security advisory](https://github.com/newbenji/ansible-collection-zitadel/security/advisories/new)
if it should not be public.
